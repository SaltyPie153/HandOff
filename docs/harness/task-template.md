# 작업 기록 양식

아래 항목을 실제 작업에 맞춰 `work/<task-id>/resume.md`에 작성한다.

- 작업 ID와 목적
- 관련 요구사항 ID(R01~R25)와 기술 설계의 관련 결정
- 변경 허용 범위와 수용 조건
- 현재 상태(진행/막힘/완료)
- 변경 파일과 실제 결과
- 검증 명령, 실행 시각, 종료 코드, 결과
- 미검증 사항과 막힌 이유
- 다음 한 단계
- 공유할 커밋 또는 산출물 위치

토큰·비밀값·전체 대화 원문을 붙이지 않는다. 같은 작업의 메모는 고정 경로에 갱신한다.
미실행 명령은 실행 증거와 분리한다. 미커밋 상태에는 커밋 ID를 꾸며 쓰지 않는다.
