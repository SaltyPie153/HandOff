# 웹 화면 정리 검증

검증일: 2026-10-04. 기준: develop의 `3ff5550`, 작업 브랜치: `feature/web-ui-cleanup`.

## 변경 내용

- 승인 회원 화면을 왼쪽 메뉴·상단 현재 위치·넓은 본문으로 구성했다. 모바일에서는 메뉴를 열고 닫는다.
- 프로젝트, 요청, 계약, 멤버 관리와 설정에 카드·상태 배지·일관된 글자 크기와 간격을 적용했다.
- 요청·제안의 본문과 사람의 확인·동의·공개 회신 입력 영역을 분리했다. 비공개 본문과 팀 공개 회신·확정 계약을 표시한다.
- 서비스 관리자 메뉴는 해당 권한이 있을 때만 표시한다. 일반 멤버 메뉴는 룸의 멤버 현황으로 연결하고 관리 담당자에게만 관리 링크를 표시한다.
- 서버 API·데이터 모델·MCP·OAuth·Solar 판정과 버전·권한 규칙의 변경은 없다. 새 의존성은 추가하지 않았다.

독립 코드 리뷰에서 같은 페이지 `#members` 이동 시 현재 메뉴가 갱신되지 않는 문제를 발견했다. `hashchange`를 구독하고 멤버 이동·개요 복귀 회귀 테스트로 수정했다. P0~P2 지적은 없었다.

## 미리보기와 검증 한계

- 새 웹은 `http://127.0.0.1:5174/projects`, API는 3310에서 실행한다. 기존 시험 DB와 OAuth 설정·보호 키 파일을 사용한다. 실제 키 값은 화면·로그·이 문서에 기록하지 않았다.
- `/dev/health`와 API 준비 상태는 HTTP 200을 확인했다. OAuth 실제 공급자 재로그인과 실제 Solar 호출은 이번 UI 검증에 포함하지 않았다. E2E의 모델 응답은 모의다.
- API 코드는 수정하지 않아 전체 DB 통합 명령을 재실행하지 않았다. 위 E2E는 격리 DB에 migration을 적용하여 실행했다.
- 기존 작업공간·시험 데이터·비밀 파일을 보존했다. 배포와 원격 반영은 별도 작업이다.
